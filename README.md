# Cerveza San Patricio

Sitio web editorial y comercial para **Cerveza San Patricio**, elaborada en San Patricio del Chañar, Neuquén.

## Arquitectura

- `index.html` — estructura semántica y contenido editorial.
- `styles.css` — sistema visual responsive.
- `app.js` — interacciones ligeras y configuración de contacto.

## Principios

1. Primera pantalla simple; profundidad en la arquitectura.
2. Mobile-first y compatible con GitHub Pages.
3. No inventar variedades, graduaciones, premios, puntos de venta ni datos del productor.
4. Separar identidad de marca, producto, territorio, persona, oficio y contacto.
5. Reemplazar primero los elementos de maqueta por fotografías, logo, textos y datos reales.
